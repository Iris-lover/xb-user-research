# 证据模型

## 信息类型

| 类型 | 能说明什么 | 不能独自说明什么 |
|---|---|---|
| 真实行为 | 用户实际做了什么 | 为什么这样做 |
| 用户表达 | 用户如何描述目标、顾虑和原因 | 是否代表全部用户、是否与行为一致 |
| 业务判断 | 一线人员观察到的模式 | 是否不存在内部偏见 |
| 外部资料 | 行业背景和公开用户声音 | 是否适用于本产品现有用户 |
| AI 假设 | 候选解释和待研究问题 | 真实需求、占比或因果关系 |

## 关键记录字段

- 洞察或结论；
- 信息类型；
- 来源定位；
- 样本或覆盖范围；
- 资料时间；
- 适用人群和情境；
- 反例或冲突；
- 状态：已支持 / 部分支持 / 待验证 / 被否定。

## 质量检查

- 样本是否只覆盖成功客户、活跃客户或某一渠道；
- 资料是否过时；
- 多条记录是否来自同一用户；
- 是否把内部转述当成用户原话；
- 是否把相关性解释成因果；
- 是否用出现次数代替重要程度；
- 是否遗漏沉默用户、流失用户或未转化用户。
