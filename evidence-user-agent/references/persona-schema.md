# 用户画像输出结构

本结构用于研究模式。画像生成后若用户要求 Agent 直接回答、评价产品或执行测试，应切换为第一人称用户模式：先输出自然的用户回答，再按需附上独立的“依据与边界”。不要把下列研究字段和证据标签逐句塞进角色回答。

## 1. 研究说明

- 产品/业务、目标用户和研究问题；
- 资料来源、覆盖范围和时间；
- 主要限制和偏差；
- 输出状态：证据驱动 / 部分证据 / 待验证。

## 2. 用户分群

对每个候选群体说明：

- 一句话定义；
- 分群依据；
- 共同模式；
- 与其他群体的关键差异；
- 样本覆盖或无法判断；
- 反例和置信边界。

## 3. 单个画像

- 用户或组织背景；
- 当前阶段和触发情境；
- 核心任务与成功标准；
- 实际行为；
- 目标与动机；
- 痛点、阻碍与失败代价；
- 当前替代方案；
- 能力、预算、时间、技术或组织限制；
- 购买/使用决策标准；
- 企业或机构的使用者、影响者、审批者、付款者与决策者；
- 真实原话及来源；
- 关键结论的证据映射。

每个资料未直接支持的画像字段都要就地标记 `[合理推断]`、`[AI假设]` 或 `[无法判断]`，尤其是风险、后果、决策角色和组织流程。

## 4. 结论与行动

- 已有证据支持的机会；
- 仍需验证的假设；
- 不应从当前资料推出的结论；
- 建议补充的用户、资料和研究问题；
- 可执行但可逆的下一步行动。

## 5. 用户模式输出

- **用户回答**：从画像用户当前目标、任务、顾虑和能力出发，以第一人称直接回答；优先描述实际影响和下一步行为。
- **依据与边界**：仅在研究复核、Agent 对比测试或用户要求来源时附加。把证据映射、合理推断与无法判断集中放在这里。
- 用户回答不能虚构个人经历或精确数值。证据不足时，用符合角色的自然表达提出需要补看的信息或说明无法决定。
