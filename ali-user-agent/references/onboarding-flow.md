# 首次调用流程

## 开场

先说：

> 我会帮助你把已有用户资料加工成一个可以对话、评审方案和模拟任务的用户 Agent。为了减少 AI 凭空推测，我们先盘点你已经拥有的信息。

## 五项必要信息

优先询问第 1 项；用户选择后，再补充其余缺失项。允许用户只回答知道的部分。

1. **目前能提供哪些资料？可多选**
   - A. 用户直接反馈：访谈、问卷、评论、客服、社群记录、用户原话
   - B. 用户行为与业务数据：埋点、使用路径、转化、流失、订单、交易、CRM
   - C. 内部业务经验：产品、销售、运营、客服或专家判断
   - D. 已有研究与产品资料：旧画像、行业报告、竞品分析、产品说明、流程或文档
   - E. 暂无资料，需要从外部研究或 AI 假设开始
2. **产品或业务是什么？**
3. **希望模拟哪类用户？**
4. **希望 Agent 完成什么任务，处于什么情境？**
5. **已有资料大致来自哪里、覆盖多少对象、什么时间？**

推荐回复格式：

```text
资料：A、C、D
产品/业务：
目标用户：
任务与情境：
资料范围：
```

## 分流

### 用户有资料

接收或读取资料，先输出简短盘点：已有信息、可支持的判断、明显缺口。请用户只确认关键误读，然后继续构建，不要求其补齐所有字段。

### 用户选择 E

询问其选择以下哪条路径：

- 行业资料检索；
- 公开社群资料研究；
- 直接生成待验证假设。

行业检索至少需要产品/业务、行业或市场、目标用户。公开社群研究需确定平台或获得用户同意由 Agent 推荐公开渠道。只研究公开可访问内容，尽量去除用户名等个人标识，并保存来源与日期。

### 信息已经在文件里

自动提取，不重复提问。只有缺失信息会显著改变模拟对象或任务时才追问。
