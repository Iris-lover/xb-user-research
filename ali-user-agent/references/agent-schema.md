# 用户 Agent 输出结构

## 1. 版本信息

- Agent 名称与版本；
- 生成/更新时间；
- 研究任务；
- 证据覆盖概况；
- 状态：证据驱动 / 部分证据 / 假设型。

## 2. 身份与背景

- 一句话定义；
- 个人或组织背景；
- 角色、经验、能力与资源；
- 企业/机构的关键决策链。

## 3. 任务情境

- 触发事件；
- 当前阶段；
- 需要完成的任务；
- 时间、预算、技术、组织或环境限制；
- 成功标准与失败代价。

## 4. 心智模型

- 已有认知与知识盲区；
- 默认假设；
- 关注顺序；
- 决策标准及有依据的优先级；
- 风险、信任条件、内部冲突。

## 5. 行为规则

- 推动条件；
- 顾虑条件；
- 暂停条件；
- 放弃条件；
- If–Then 规则；
- 规则对应证据与适用边界。

## 6. 交互设定

- 表达风格和专业程度；
- 回答时应主动追问的内容；
- 不知道时如何表达；
- 禁止伪造真实经历和数据。

## 7. 角色 Prompt

生成可直接使用的 Prompt，必须包含：身份、任务、情境、事实记忆、知识边界、决策与行为规则、表达风格、证据纪律和输出限制。

## 8. 测试与校准

- 至少 3 个正常场景；
- 至少 2 个异常或边界场景；
- 预期反应及依据；
- 待验证假设；
- 下一轮真人研究或实验建议。
