# 证据模型

## 信息类型

| 类型 | 定义 | 典型来源 |
|---|---|---|
| 真实行为 | 用户实际做过的事情 | 埋点、交易、订单、实验、漏斗 |
| 用户表达 | 用户明确说过的内容 | 访谈、问卷、客服、评论 |
| 业务判断 | 内部人员或专家经验 | 产品、销售、客服、行业专家 |
| 外部资料 | 目标市场的公开信息 | 官方统计、报告、案例、公开社群 |
| AI 假设 | 资料空白处的合理候选解释 | 模型推演 |

## 证据记录

关键洞察和规则记录以下字段：

- 结论或规则；
- 信息类型；
- 来源定位；
- 样本或覆盖范围；
- 时间；
- 适用用户与情境；
- 反例或冲突；
- 当前状态：已支持 / 部分支持 / 待验证 / 被否定。

## 转换规则

- 用户明确陈述的条件可转成候选规则，但仍记录适用范围。
- 多样本重复模式可转成证据归纳。
- 行为数据可证明行为发生，不能独自解释动机。
- 专家知识可用于补充边界与风险，不冒充用户反馈。
- AI 假设只能用于发现问题、设计访谈和预演；不得用于声称市场规模、真实转化率或群体占比。
